# 企业级循环盘点执行治理

上海如静知华信息科技有限公司（[知华科技](https://www.zhuatech.cn/)）将任务下发、现场盘点、差异复盘、调整过账和库区解冻组成可追溯闭环。

- 区域冻结与盲盘，避免账面数量和并发移动干扰现场结果。
- 批次/序列号完整追溯，盘点提交使用幂等键防重复。
- 超容差差异强制独立复盘、根因确认和授权审批。
- 执行人与审批人职责分离，保存影像证据，过账后检查解冻。

接口：`POST /api/enterprise/wms/cycle-count-execution`，返回 `POST / REVIEW / BLOCKED`、风险等级和审批路径。
